# Pancreatic Cancer in LMICs — Value of Lost Welfare: Reproducibility Package

Analysis code for *Economic welfare burden of pancreatic cancer in low- and middle-income countries:
trends from 1990 to 2023 and projections to 2050* (manuscript ISCIENCE-D-26-05974).

The study quantifies the welfare-based economic burden (value of lost welfare, VLW) of pancreatic
cancer across 122 low- and middle-income countries from 1990 to 2023, and projects it to 2050.

## Repository contents

| Path | Contents |
|---|---|
| `scripts/` | The complete analysis: entry point, canonical implementation, submission-table builder, and the additional reviewer-requested analyses |
| `fig/` | The 19 manuscript figures under their manuscript names, plus a standalone script for each one (see `fig/README.md`) |
| `RUN_LOG_2026-08-14.txt` | Console log of a full pipeline run |
| `LICENSE` | Licence |

**Input data are not redistributed here.** `data_raw/` and the generated `outputs/` are excluded;
see *Obtaining the input data* below. Every output is regenerated by running the scripts.

## Scripts

| Script | Purpose |
|---|---|
| `run_LMIC_Pancreatic_VLW_R3.R` | **Entry point.** Resolves the working directory and sources the canonical implementation. |
| `run_LMIC_Pancreatic_VLW_v2.R` | The complete implementation, kept under its historical filename for continuity. Not called directly. |
| `run_R5_reviewer_analyses.R` | Rolling-origin forecast validation, sex-specific reconciliation, exclusion fractions by income group, and the fixed-composition sensitivity analysis. |
| `make_submission_xlsx.R` | Builds the submission xlsx tables from the generated CSVs. |

```bash
Rscript scripts/run_LMIC_Pancreatic_VLW_R3.R    # full analysis: figures, tables, diagnostics
Rscript scripts/run_R5_reviewer_analyses.R      # additional validation analyses -> outputs/R5/
Rscript scripts/make_submission_xlsx.R          # submission tables as xlsx
Rscript "fig/code/make_all_figures.R"           # all 19 figures, or one script per figure
```

The full pipeline takes about 20 s; the figure scripts about 65 s.

## Obtaining the input data

Place the following under `data_raw/` before running:

- `data_raw/gbd_daly_yearly/measure2_DALYs_year{1990..2023}.csv` — 34 annual pancreatic-cancer DALY
  extracts (cause 456, measure 2) from the **GBD 2023** results tool at
  <https://vizhub.healthdata.org/gbd-results/>, for all 204 locations, both sexes and all age groups,
  in both number and rate metrics.
- `data_raw/external_metadata/HALE.csv` — GBD 2023 healthy life expectancy.
- `data_raw/external_metadata/gdp.csv` — World Bank World Development Indicators,
  `NY.GDP.PCAP.PP.CD` and `NY.GDP.MKTP.PP.CD`.
- `data_raw/external_metadata/204_with_LMIC.csv` — GBD location list with the World Bank income
  classification flag.
- `data_raw/external_metadata/df_world2.geojson` — world map geometry keyed by GBD `location_id`.

GBD and World Bank data are redistributed under their own terms, which is why they are not committed
here.

## Statistical policies implemented

- Historical marginal lower/upper bounds are never summed. Aggregate historical 95% uncertainty
  intervals are not reported, because matched GBD draws are unavailable.
- DALYs are the primary projection estimand; projected DALYs are then monetised using fixed 2023
  income-group effective VSLYs.
- Every reported forecast interval uses `level = 95` explicitly.
- All-LMIC prediction intervals use 50,000 joint simulation paths and the empirical
  residual-correlation matrix; subgroup interval endpoints are never summed.
- The rate panel is the unweighted mean of country-specific age-standardised DALY rates.
- One discounted-annuity VSLY definition is used throughout; both-sex values are male plus female.
- IE = 0.5, 1.0 and 1.5 are valuation scenarios, not statistical uncertainty bounds.

Reference constants: US DOT 2023 VSL = US$13.2 million; US 2023 PPP GDP per capita = 82,304.62
international $; base discount rate 3%.

### Forecast model

The manuscript reports both exponential smoothing (damped-trend ETS) and automatically selected
non-seasonal ARIMA. `run_R5_reviewer_analyses.R` performs rolling-origin validation across 14
forecast origins and horizons of one to six years, with naive and drift benchmarks, and reports
horizon-specific errors together with the empirical coverage of the nominal 95% prediction
intervals. See that script's outputs in `outputs/R5/` for the model comparison underpinning the
model choice reported in the manuscript.
